# Placeholder card design

This is the stand-in design, not the approved one. It exists so the pipeline (intake, queue, Browser Rendering, R2, personal page) can be built and tested end to end before SPC's design arrives. Its layout lives entirely in `src/render/template.ts` (deep blue gradient, white type, gold accent line, cyan small-caps labels, a CSS-text "SPC FREE ZONE" wordmark because no logo file exists yet, and an empty reserved QR square), with the metrics for the four sizes in `TEMPLATE_METRICS` and the fonts in `templates/fonts/`. The real design is delivered per `docs/DESIGN-HANDOFF.md` (eight layouts, reference PNGs, font files, text rules) and replaces the layout in `template.ts` under a new `TEMPLATE_VERSION` in `wrangler.toml`, in a folder `templates/spc/<version>/`; cards rendered with `placeholder-1` can then be re-rendered selectively from the admin. Test cards carry a diagonal TEST watermark regardless of design.
