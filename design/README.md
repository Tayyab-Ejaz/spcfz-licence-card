# Design source

Unpacked from SPC's Claude Design exports by `tools/extract-design.mjs`.
Do not edit by hand: re-export, re-extract, rebuild, and run the pixel
comparison (docs/DEV.md, "Updating the design").

| Path | From |
|---|---|
| `source/studio/` | License Announcement Studio - Standalone.html (desktop) |
| `source/mobile/` | License Announcement Mobile - Standalone.html (phones) |
| `source/assets/` | fonts and images shared by both, named by content hash |

Extracted 16 October 2026. Fonts: Inter and Noto Kufi Arabic (SIL Open Font
License) and Phosphor icons (MIT), as bundled by the design.
